## 4. 재는 법(반드시 이 길로)

1. `python research/registry.py find <단어> [--family 계열]` 로 같은 가설이 있는지 먼저 본다. `show H0333` · `stats`.
2. 없으면 `add` 로 **시험 전에** 등록한다. 번호는 add 가 매긴다(손으로 H 번호를 짓지 말 것).
3. 명세(`research/specs/_template.json`)를 쓰고 `python research/run_spec.py <명세> [--dry]`.
   - 0 등록부 대조·미래 열 차단 → 1 지연 검정 → 2 학습(2016~22) → 3 이웃 변형 → 4 검증(2023~)·최근 두 해·다중검정(DSR 0.90)·가짜 달력 → 5 겹침.
   - 명세는 첫 실행 때 해시로 고정된다. 사후에 고치면 새 가설이다. 시험 칸 수는 자동으로 적힌다.
4. 통과하면 '후보' → 그림자(돈 없이 미래 날짜로 채점) → 1주 실주문 시험 → 사전 등록 판정(`research/prereg/registry.json`, 매일 21:10 `judge.py`) → 채택.
5. 자유 스크립트를 쓰면 파일 이름에 날짜를 붙이고(`xxx_1118.py`) 보고서를 `research/reports/` 에 남긴다.

### 판정 관문(전부 넘어야 함)

- **절대 수익**으로 판정한다. 시장 대비 초과만 플러스면 탈락.
- 학습 2016~22 · 검증 2023~. 최근 해 진입분이 지면 탈락. 가능하면 2005~15 홀드아웃도.
- 비용: 국장 왕복 0.23%(수수료 0.015×2 + 거래세 0.20). 미장 토스 왕복 0.20% + 스프레드.
- 사건·장중·데이 규칙은 **날 바구니**(하루 평균을 한 표본)로 t 를 잰다. 거래 단위 t 는 부풀려진다.
- 보유 40일↑는 같은 날 아무 종목 대조와 견준다.
- 관문 4종(`research/factory/gates.py`): 복권형(상위 5% 빼면 ≤0) · **거울(뒤집은 짝도 플러스면 탈락)** · 이웃 문턱 · 가짜 달력(같은 날 같은 개수 무작위 1,000판 상위 5%).
- 거르개(조이기)는 무작위 같은 비율 빼기 300시드와 견주고, **계좌 시뮬까지** 본다.
- 체결 가능성: 상한가·하한가 마감 값에 샀다고 치지 않는다. 단일가 체결액·호가 깊이를 확인한다.

## 8. 자주 밟은 함정

- 같은 하락을 며칠 중복 계산(보유 중 재진입 금지로 실거래 건수를 낼 것).
- 조건 열이 폐지 종목에 비어 있어 '걸러낸 게 아니라 안 본 것'이 되는 생존편향.
- 성적이 2020년 한 해·몇 달에 몰림(월 블록 부트스트랩을 같이 낼 것).
- 기준선 잘못 잡기: 조건이 부분집합에만 걸리면 기준선도 그 부분집합.
- 보유기간이 다른 것끼리 같은 기준선에 견주기.
- 살 수 없는 값에 샀다고 치기(상한가 마감 종가, 낙관 트레일 체결).
- 공매도 잔고 T+2, 신용 L=3, 내부자 +1일 같은 **공개 시차**.
- 국장 `change` 칸은 등락률이 아니라 '원' 변동. 코스닥 2018~ 일부는 시가 없음.
- 미장 옛 패널(us_scan)은 살아남은 종목뿐 → `us_scan_full` 을 쓸 것. 폐지 종목 수정주가 깨짐(-95~+500%로 자를 것).
- NaN 이 든 JSON 은 사이트가 표를 통째로 버린다(`allow_nan=False`).

## 9. 운영 규칙(이 저장소에서 꼭 지킬 것)

- **실전 코드와 원장은 건드리지 않는다**: `autotrade.py` `day_alert.py` `nxt_pre.py` `nxt_shadow.py` `day_crmap.py` `day_heat.py` `collect_m1.py` `toss.py` `index.html` `assets/` `supabase/` `.github/` `data/autotrade/` `data/day/`. 규칙 채택·금액·새 예약 작업은 주인 승인이 있어야 한다.
- 비밀은 `.env` 에만. 출력·커밋·문서에 넣지 않는다. 이 저장소는 공개다.
- 연구 스크립트는 `python research/memguard.py [--gb 16] 스크립트.py` 로 감싼다. 하나당 16GB, 시작 전 남은 메모리 20GB 이상, 같은 스크립트 중복 실행 금지. `portfolio.py` 를 통째로 돌리면 17GB — 신호표(`port_sig.pkl`)를 쓸 것.
- KRX 는 저속·순차로만. 토스 호출은 초당 20회를 실전 작업과 나눠 쓴다(장중엔 양보).
- 커밋은 내가 만든 파일만 `git add` → `git pull --rebase --autostash` → `git push`. `research/hypotheses.jsonl` 과 `data/trials.json` 은 실행기가 관리한다.
- 고친 뒤엔 `python selftest.py` 가 '전체 통과'여야 한다.
- 실측은 **말한 그대로 판과 변형 판(문턱·창·매도 시점·대상·국면)** 둘 다 낸다. 규칙은 안정성이 먼저다(한 해 대박보다 해마다 플러스).
